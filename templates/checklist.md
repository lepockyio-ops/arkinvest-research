# 发布前检查清单（结果放入附录 I；任何 [必须] 项未通过不得交付）

### 格式

- [ ] 标题含对象、指标、方向/数值、期限、情景口径；标题数字 = 正文基准情景，单位一致
- [ ] 元信息栏完整：作者角色、发布日期、数据截止日、价格基准日、利益声明、版本
- [ ] 摘要含 6 个要素；摘要中的每个数字在正文出现且数值一致
- [ ] 每张图有结论式标题、来源行（机构 + 文档 + 日期）、单位、实际/预测区分；关键数字在正文或附录表格中可找到
- [ ] 风险章节 ≥ 3 项，每项含机制、可能性、量化影响、监测指标；有独立的最强反方解释
- [ ] 每个脚注编号都有对应内容；没有占位符（如 “X%”“TBD”）；没有本地文件链接、编辑器残留代码、邮件跳转链接、重复段落
- [ ] 术语首次出现时已定义；同一缩写只指一个概念

### 证据

- [ ] 台账覆盖全文所有数字，必填字段齐全；链接直接定位到数字所在位置
- [ ] 派生数字全部重新计算，结果一致；增长率与起止值相符；单位换算已核对
- [ ] 重要主张满足 §12.2 的最低核验标准
- [ ] 所有冲突已按 §13 处理并记录
- [ ] 每个数字和关键判断都有证据标签；管理层说法未被当作事实或验证使用
- [ ] 无 L6 来源作为唯一依据；利益相关方材料已注明立场
- [ ] 已完成反方检索、失败案例、旧预测复盘
- [ ] §15.2 的偏差清单已逐项回答
- [ ] 所有“导致”类表述已通过 §15.3 的 6 个问题
- [ ] 情景设计满足 §15.4：下行覆盖现状与恶化；熊市不含未存在业务；倍数随情景变化；报告了中位数与分位数
- [ ] 每个核心结论有验证表和可观测的证伪条件
- [ ] 与本机构以往报告的同一数字已对比，差异已解释
- [ ] 利益关系与作者角色已披露
- [ ] “无法确认的事项”清单已列出

### 调查过程

- [ ] 问题陈述模板已写全；驱动树的需求侧和供给侧都有约束
- [ ] 已预先写下 3 条“会改变结论的证据”（附录 B）
